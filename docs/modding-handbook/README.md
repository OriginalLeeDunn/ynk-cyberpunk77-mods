# YNK Cyberpunk 2077 Modding Handbook

Things we learned the hard way while making PC and console (mod.io) mods for Cyberpunk 2077 2.5, written so
you don't have to. Every statement here was checked in game or with the game's own tools, not copied from a
guide; where something is only reported by others it says so. Corrections welcome (open an issue).

- [1. When the game won't start](01-game-wont-start.md): what each kind of failure looks like and where the evidence is
- [2. Console and mod.io script mods](02-console-script-mods.md): the native script path, its gotchas, and how we test it
- [3. Testing mods in game](03-testing-in-game.md): the lab approach and what misleads you

Companion tool: [Mod Doctor](../../tools/cp77-mod-doctor/) automates the checks in chapter 1.
